# 测试资源规则

从[验收场景](README.md)确定结果，用正式入口断言。测试和 mock 的环境、保留与回收遵循[资源协议](../docs/development-lifecycle.md)，通过 `pnpm test` 或 `pnpm test:browser` 验证。

创建夹具时，先确定资源归属和清理顺序。把进程、服务、浏览器关闭和目录删除放入同一个可等待的清理过程，先回收进程再删除记录。保存 PID 与启动身份后再运行可能失败的断言。

故障用例只损坏自己创建的副本。外层保留恢复所需的身份和配置，断言失败也要回收本轮子进程。不能根据命令名称或时间猜测 PID 后终止进程。

日志和截图使用 runner 分配的位置，不写固定系统 `/tmp` 路径或源码目录。成功回收，失败保留原因及精确命令。未验证的宿主、平台或外部工具结果单独说明。
