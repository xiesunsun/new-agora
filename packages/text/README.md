# Markdown 与差异

保留原文件中的 BOM、CRLF 和 Unicode 字符。选区与修改范围按原文定位。若渲染后的选区无法可靠对应到原文，请用户重新选取。

审阅差异比较本轮底稿和待审稿。历史差异比较两次已登记的正文。应用预览从底稿重建，只加上用户保留的修改。能独立应用的修改可以分开选，互相依赖的修改一起处理。范围不明确或重叠无法安全应用时，交给服务提示用户核对。

用重复文本、emoji、BOM 和 CRLF 验证定位与原文保留。参见[选区定位验收](../../tests/README.md#a08)。

新一轮审阅通过 reviewUnitsBetween 生成标题、句子或段落单元。句内增删和替换属于同一次选择。细节划线只用于显示。超限或精确重建失败时退回整稿比较，全部接受与全部保留仍精确。已保存审阅的范围、编号和选择保持原样。
