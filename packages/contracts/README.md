# 运行时契约

接口字段、枚举和结构校验由参考实现 `next/packages/contracts/src/` 中的 schema 维护。变更契约时，同步更新入口、消费者和对应协议测试。

| 入口 | 范围 |
| --- | --- |
| `documents.ts` | 文档投影、导入、正文、版本与命令回执 |
| `work.ts` | 批注、任务、执行上下文与文件计划 |
| `review.ts` | 审阅投影、决定与确认 |
| `p0.ts` | 早期独立探针，供历史调研 |

形状校验在接入边界完成。调用范围、阶段和条件写入由[服务](../../apps/service/README.md)校验。普通面板身份只可使用人类业务入口；文件和执行入口要求可信本地 worker 或受控宿主适配器。协议故障见 [A02](../../tests/README.md#a02)与 [A05](../../tests/README.md#a05)。
