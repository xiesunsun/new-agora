# 接口约定

把请求字段、允许的取值和校验放在本包。改接口时，同步更新接收方、调用方和测试。

| 操作 | 要核对的内容 |
| --- | --- |
| 开始生成 | 文稿、当前对话、已保存的工作稿和本轮批注 |
| 领取与提交 | 本轮执行身份。领取返回待审路径和用户意见，提交后由服务读取结果并计算差异 |
| 保存审阅选择 | 当前待审稿、具体修改项和用户决定 |
| 应用到原文件 | 用户核对过的预览、当前文稿和稳定的操作编号。相同编号与相同内容只生效一次 |
| 查询版本与应用结果 | 已登记的版本，以及写入中、待核对或已写入的状态 |

字段校验在接口入口处理。对话归属、有效执行和原文件写入条件由[本地服务](../../apps/service/README.md)核对。Codex 通过本轮执行身份提交结果，底稿和版本的关联由 Agora 记录。

Ink 面板继续使用同一异步 PanelTransport。任务命令携带当前修订与 roundId，结束未知的执行不能被新任务替代。历史采用只切换工作稿基点。写入回执关联原 operationId 与来源输入修订，recheck 只核对原操作。版本记录保留实际保存时间，旧记录缺失时间时保持未知。
