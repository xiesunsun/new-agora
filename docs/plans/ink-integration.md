# Ink 正式接入实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 将已确认的墨间界面接入真实服务，使 mock 场景可独立维护，并清理被替换的实现。

**Architecture:** 面板通过 PanelTransport 读取状态和提交命令。服务是草稿、审阅、写回与版本的唯一写入方。mock 复用服务，只替代 Codex 执行，并使用临时 Markdown 和数据库。

**Tech Stack:** TypeScript、浏览器 DOM、Node.js、SQLite、esbuild、Playwright。

## 吞吐检查点

- Blocking first steps。固定共享契约与领域状态，再开始依赖它们的面板工作。
- Independent workstreams。服务、文本算法和面板按文件归属分开。文档与 Git 集成由主代理负责。
- Shared mutable state。契约保留单一负责人。工作流状态只由服务写入，UI 临时状态不镜像保存结果。
- Smallest safe decomposition。先用真实服务和现有执行器完成 mock。只在实际故障场景需要时提取外部依赖接口。

## 面板行为验收表

| 原型行为 | 预期结果 | 验证入口 |
| --- | --- | --- |
| 生成前保存失败 | 保留输入与批注，不发起生成 | 控制器延迟与失败测试 |
| 批注失去定位 | 保留意见、阻止生成，重新关联后可生成 | 正式面板浏览器测试 |
| 中文输入法 | 确认候选文字不提交批注，Enter 才提交 | 正式面板组合输入事件测试与浏览器观察 |
| 已选建议回看 | 展开只读比较，不改变选择、数量、版本或保存权限 | 正式面板与服务状态核对 |
| 历史返回 | 恢复工作稿滚动、焦点、选区和批注回看 | 正式面板浏览器测试 |
| 放弃确认 | 默认继续编辑，取消后内容和焦点不变 | 正式面板浏览器测试 |
| 窄窗与减少动态效果 | 操作可达、无横向溢出，减少动态时立即显示最终结果 | 390、760、1280 宽度截图与浏览器检查 |
| 保存与恢复 | 副本文字、版本和操作身份一致，重开不重复登记 | 正式服务完整闭环 |
