## 已确认的问题

只有启动 hook，没有任务收尾 hook。已知 GitHub 连接器创建 PR 返回 403，却没有可执行的后续路由规则。mock 与截图存在未回收的系统临时目录。原型代号进入了当前模块和文档名称，没有单独的正式命名决策。

## 设计与归属

两个独立方案与交叉审阅选择显式收尾检查点。`Stop` 是回复结束事件，不能代替任务完成判断。主代理请求收尾后，hook 最多请求一次续跑，当前代理完成复盘。程序检查记录和证据，不调用另一个模型。

任务记录只有一份执行目录与 session 绑定。收尾回执绑定最终提交、文件摘要、复盘和资源记录。native 聊天 ID 不当作已观测的 hook session ID。

任务脚本与 hook、开发运行资源、面板职责改名分别由独立实现者负责。主代理负责共享协议、依赖配置、文档、历史资源整理及最终集成。三部分共享状态根选择规则，源码模块接口保持公开入口。
