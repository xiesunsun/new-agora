# 产品范围

Agora 让用户和当前 Codex 对话协作编辑一份 Markdown。用户在面板阅读、编辑和批注。Codex 根据批注在绑定的原文件上操作，Agora 将实际修改登记为待审阅的差异。用户决定哪些修改进入工作正文，并明确确认正式版本。

| 概念 | 含义 |
| --- | --- |
| 工作正文 | 用户正在编辑的内容，包含已保存的人类修改和已接受的 Agent 修改 |
| 正式版本 | 可回看的不可变正文快照 |
| 原文件 | 用户通过可信本地入口明确绑定的 Markdown 路径 |
| 候选修改 | 从 Agent 实际文件修改中计算的差异，供用户决定 |
| 本机草稿 | 面板中尚未确认送达服务的输入 |

首期范围是一人、一份正在协作的文档、一条当前 Codex 对话执行链路。独立浏览器可完成用户编辑和版本流程。绑定原路径与 Agent 执行使用可信本地入口。多人实时编辑、云端执行与自动语义合并属于后续设计。

开发时按[文档索引](README.md)选择流程。跨模块的状态归属见[架构](architecture.md)。
