# 产品范围

Agora 让你在当前 Codex 对话里改一份 Markdown。打开原文件后，你可以自己编辑，也可以留下批注。点 **生成修改建议**，Codex 在一份待审稿里改写。Agora 标出实际变化，你选好要保留的内容，再点 **应用到原文件**。写回成功后，历史中出现这次保存的版本。

| 名称 | 你看到的是什么 |
| --- | --- |
| 工作稿 | 你正在编辑的正文。保存草稿会保留你的输入。 |
| 本轮底稿 | 点 **生成修改建议** 时保存下来的工作稿。 |
| 待审稿 | Codex 在这轮交回的 Markdown。Agora 用它和底稿算出修改建议。 |
| 应用预览 | 底稿加上你选中的建议。你可以随时改变选择。 |
| 原文件与历史版本 | 原文件是磁盘上的 Markdown。历史保存首次打开的原文，以及后来成功应用的正文。 |

首版面向一人、一份已绑定的 Markdown 和当前 Codex 对话。一轮可以带多条批注，使用一种审阅界面。可以查看已保存的历史版本。一轮改稿期间，用户通过 Agora 编辑这份文稿。并行使用其他编辑器修改原文件的场景暂不纳入。独立浏览器入口、逐条即时生成、第二种审阅界面和完整的历史恢复操作放在首版之后。
