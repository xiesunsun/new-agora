# 原生编辑与 Markdown 源码

Agora 既提供直接编辑，也把本地 Markdown 作为批注坐标和写回内容。成熟编辑器解决选区、组合输入和撤销，但原生文档与 Markdown 并非逐字节等价。整稿序列化会改变未编辑内容，要求每次输入立即往返相等也会把普通尾空格判为失败。

工作稿使用持久 Crepe 实例，源码投影保留未编辑的结构与间隔。变化仅在实际编辑的完整结构内序列化。快照是投影信息，不另存一份业务草稿或撤销栈；控制器和服务继续拥有输入、任务、选择、磁盘与版本。

这种边界接受被编辑结构内的 Markdown 写法规范化，保留其他结构的原始字节。无法可靠投影时保留原生输入与最近有效源码，显式恢复，不退回整稿规范化或搜索相似文字猜测位置。不支持的导入内容继续提供原文编辑能力。具体契约和限制由[面板说明](../../apps/panel/README.md)维护。

逐字符来源账本可保留更小的修改范围，但需要额外协调原生历史、节点身份与删除恢复。当前采用较小的结构快照，并用真实依赖验证完整替换、分散修改、引用定义、组合输入和撤销边界。

审阅保持服务原有的修改编号与选择。显示先解析完整 Markdown，再按源码区间装饰和提取，避免把任意差异碎片当成独立 Markdown。行内样式和修改标记属于显示内容的一部分，不能因提取 DOM 范围而丢失。
