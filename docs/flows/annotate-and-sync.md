# 批注与生成修改建议

1. 在工作稿上选一处文字，点出现的批注笔尖留下修改意见。列表、链接、代码和行内格式可以直接选字。只有包含暂不支持内容的文稿才需要例外的 **编辑原文** 模式，在其中选字后点 **批注选中文字**。你可以先收集几条，改写或撤回还没交给 Codex 的意见。
2. 点 **生成修改建议**。Agora 保存本轮底稿和当时的批注。底稿包含你已保存的人类编辑。面板显示 **等待 Codex**，实际领取后显示 **正在改稿**。
3. 当前 Codex 收到批注原话、对应段落和待审 Markdown 路径。它用平常的文件工具编辑待审稿，完成后交回本轮产物。原路径可以提供阅读上下文，改稿的写入目标是待审稿。
4. Agora 读取并保存交回的正文，和本轮底稿比较。面板展示实际差异。如果没有差异，提示 **没有新建议**。一条批注可以产生多处改动。

同一文稿每次只生成一份待审稿。批注之间需要顺序时，按用户留下的顺序交给 Codex。选区找不到原来的文字时，请用户重新选择。生成中断或结果未知时，面板保留工作稿与批注并显示 **生成中断，待核对**。确认原执行结束后，用户可以用这些批注重新生成。旧执行结束或退出本轮后交回的结果不能替换当前待审稿。
