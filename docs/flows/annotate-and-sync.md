# 批注与原文件同步

在面板选中原文并提交批注，Agora 保存批注并排队。可信本地入口可明确绑定 Markdown 原路径。绑定已有文档时，文件原文须与工作正文一致。

| 阶段 | 用户可观察的结果 |
| --- | --- |
| 已排队 | 批注出现在文稿和任务列表。宿主收到唤醒后，任务继续等候实际领取。 |
| 已领取 | 当前对话处理已领取的批注。执行者先同步已保存的人类输入，再用原生工具编辑绑定文件。 |
| 已登记候选 | Agora 从真实文件变化登记差异。用户工作正文与正式版本继续保留原值，直到用户作出决定。 |
| 发生冲突或结果未知 | 面板保留双方内容与任务现场。用户可核对；确定失败后才可明确重试。 |

排队和文件结算由[服务](../../apps/service/README.md)负责。[worker](../../apps/worker/README.md)描述操作与恢复，[桌面适配器](../../plugins/desktop/README.md)描述当前对话接入。候选进入[集中审阅](review.md)。验收见 [A03](../../tests/README.md#a03)、[A06](../../tests/README.md#a06)至 [A10](../../tests/README.md#a10)。
