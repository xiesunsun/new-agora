# 集中审阅

用户选择 **润笔** 后收束本轮输入。面板先处理前序保存，服务再冻结本轮，等待已登记的任务与文件操作结算。等待期间继续处理已登记的工作。

| 操作 | 用户可观察的结果 |
| --- | --- |
| 通篇或逐条审阅 | 两种方式展示同一组修改及其决定。依赖项须按可接受顺序处理。 |
| 接受或拒绝一项 | 接受更新工作正文，拒绝保留当前正文。此时正式版本和原文件保持原状。 |
| 确认审阅版本 | 正文有变化时新增正式版本。剩余项必须逐项决定，或由用户明确丢弃后确认。 |
| 对齐原文件 | 服务核对实际文件与本次目标一致后结算。确认完成时仍可能显示待对齐。 |

无可审差异时回到收集状态，保留未确认的人类正文。批量决定中遇到冲突或未知结果时暂停。重开后保留已生效的决定，同一接受请求只生效一次。

[面板](../../apps/panel/README.md)拥有展示与请求恢复，[服务](../../apps/service/README.md)拥有冻结、决定、确认与对齐计划，[worker](../../apps/worker/README.md)提供独立核对入口。先跑 [A01 完整闭环](../../tests/README.md#a01)，再核对 [A05 丢失接受回执](../../tests/README.md#a05)和 [A10 文件回执](../../tests/README.md#a10)。
