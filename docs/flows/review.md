# 审阅与写回

面板比较本轮底稿和 Codex 交回的待审稿，展示实际增加、删除或替换的文字。能够独立应用的修改可以分开选，共同才能成立的修改一起展示。点击 **保留** 或 **舍弃** 只改变应用预览。预览只加入已选为保留的修改，点应用前可以改主意。

例如，你已把标题改成「交付方案」，Codex 又建议「周四上午完成初稿」和「下周一交付」。你只保留第一处。预览包含你的新标题和周四初稿，交付日期沿用底稿。审阅只展示 Codex 建议的两处差异。保存后比较历史版本时，你改的标题也属于版本差异。

核对预览后，点 **应用到原文件**。Agora 写入预览里的正文。自己编辑的工作稿也可以直接应用。写入后重新读取文件，核对成功并登记版本，面板才显示 **已写入原文件 · V2**。正文与当前正式版本相同时沿用该版本编号。

如果写入中断或结果未知，显示 **正在核对写入结果**。保留应用时选好的内容，核对原来的这次写入后再给出结果。
