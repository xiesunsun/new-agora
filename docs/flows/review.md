# 审阅与写回

面板比较本轮底稿和 Codex 交回的待审稿，在正文原处展示完整原文与建议。完整标题是一项选择，句内增删和替换一起选择。能够独立应用的句子或段落可以分开选。细节划线只帮助阅读，不增加修改数量。

上下文、原文和建议保持 Markdown 的列表、链接、强调、代码与标题结构。原文使用紧凑对照，建议使用正文排版。接受或保留原文后，对照收起为所选正文和页边标记；从标记回看可改变同一项选择。选择与回看不会写原文件。原位收起保留阅读位置，减少动态效果偏好停用位移动画。

每项选择 **接受** 或 **保留原文**。选择只改变服务计算的应用预览。已选项收起后，可以从页边页签重新展开并改选。回看本身不改变选择、版本或保存权限。所有待选建议处理完后，才可保存。

例如，你已把标题改成「交付方案」，Codex 又建议「周四上午完成初稿」和「下周一交付」。你只接受第一处。预览包含新标题和周四初稿，交付日期沿用底稿。审阅只展示 Codex 的建议，历史版本差异也包含你改的标题。

点 **保存** 或按 Command + S，服务核对用户确认的预览和原文件。写入后读回一致并完成版本登记，面板才显示成功。正文与当前正式版本相同时沿用该版本编号。全保留原文时，自己的正文编辑仍可保存，批注继续保留。

写入中断或结果未知时，保留原操作编号、写入前正文和目标。**重新核对写入** 只读取并核对原操作，不再次写入。外部冲突不能被覆盖。迟到的成功回执只能确认原操作，不能把较晚的编辑标为已保存。

**结束审阅** 退出本轮并保留原工作稿和批注。仍有待选或接受的建议时，先说明退出后果并确认。取消后继续原来的审阅。
