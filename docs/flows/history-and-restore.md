# 查看历史版本

版本入口打开连续文稿数轴。每张稿页对应一个真实保存版本，显示版本号和实际保存时间。旧记录缺少时间时显示时间未记录。滚轮、拖动和键盘可以选择版本。

浏览历史只读，不写原文件、不新增版本，也不改变工作稿与审阅选择。返回工作稿或审阅时，恢复原来的阅读位置、焦点与选区。历史只在原文件读回核对并登记版本后更新。

点 **从此版继续写**，将所选版本作为当前工作稿的基点。当前有未保存正文、批注或待处理建议时先确认，默认继续编辑。放弃并切换后清除当前批注和审阅上下文，已保存版本保留。生成、批注编辑和写入期间不能切换。持久化失败时保留原来的工作稿与上下文。

切换本身不写原文件、不新增版本，也不产生待保存的正文修改。后续真实编辑才可以保存。工作稿基点与磁盘最新版本分别记录，未来保存仍核对磁盘最新版本，避免用历史正文覆盖外部修改。
