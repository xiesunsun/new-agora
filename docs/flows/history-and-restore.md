# 历史与恢复

历史预览为只读操作。切换历史版本或返回工作界面时，当前工作正文、审阅决定与原文件保持原状。快速切换时，面板只显示最后选择的版本。

恢复须由用户明确发起。目标正文与当前正式版本不同时，服务追加一个新版本并记录恢复来源。例如在 V2 恢复 V1，得到来源为 V1 的 V3。恢复也可用来替换未确认工作正文；如果正式正文相同，沿用当前正式版本。

有未确认的编辑时，用户可以先确认当前正文，或明确选择替换。前序保存失败时暂停恢复。集中审阅、活动工作、待决定修改或未结算的文件写入会阻止恢复。绑定原文件时，对齐仍需实际核对。

查询与界面切换见[面板](../../apps/panel/README.md)，版本边界见[服务](../../apps/service/README.md)。复现路径见 [A11](../../tests/README.md#a11)。
