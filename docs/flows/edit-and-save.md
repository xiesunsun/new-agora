# 打开文稿与保存草稿

在 Codex app 当前对话里提供一份已有 Markdown 的绝对路径，让 Agora 打开。该路径对应一个项目，插件自动启动所属服务。面板读取原文件作为工作稿，并把首次读取的正文记为 V1。重开同一路径时，先恢复服务保存的工作稿和协作进度；省略路径可恢复当前对话最近打开的项目。

提供新的 Markdown 路径会打开独立项目。已打开的面板继续操作原稿件。宿主结束插件连接后服务关闭，工作稿和历史保留；下次打开同一路径继续。另一个活动对话不能接管已经打开的同一项目。

正文编辑与已确认批注保留在工作稿中，不立即写原文件。点 **保存** 或按 Command + S 才把当前正文写回磁盘。服务核对原文件、执行写入并读回，核对成功后登记版本。同一正文不重复新增版本。

项目已打开时，原文件暂不可读不会阻止保留工作稿、批注或查看历史。保存仍需核对原文件；路径不可读、规范路径改变，或磁盘正文与最近保存的版本不一致时停止写回，不另建文件替代，也不覆盖外部修改。

点生成前先保留最新输入。保留失败时，输入和批注仍在，任务不交给 Codex。正文变化后无法定位的意见不会被删除。重新选中原句并关联后，才能带上这些意见生成。

标题、列表、链接、强调、代码和表格可以直接编辑与批注。选中文字显示轻量格式菜单，点击已有链接可修改地址；在空行输入 `/` 选择标题层级或插入结构。打开批注、浏览历史和返回工作稿时保留原生编辑器与撤销记录。

仅打开和批注不改写 Markdown。实际编辑可能规范化被编辑结构的 Markdown 写法，其他结构保留原文与换行。包含暂不支持内容的文稿保留安全阅读和 **编辑原文** 入口，改好后可 **返回文稿**。无法可靠保留当前修改时，面板提示撤销恢复，并保留当前编辑的只读副本。源码保留与支持范围见[面板说明](../../apps/panel/README.md)。

批注输入中，Enter 确认，Shift + Enter 换行。中文输入法确认候选文字不提交意见。取消有修改的输入前先确认，取消确认后继续原来的输入。
