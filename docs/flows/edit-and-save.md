# 打开文稿与保存草稿

在当前 Codex 对话里打开并绑定一份已有的 Markdown。面板读取原文件作为工作稿，并把首次读取的正文记为 V1。重开同一份文稿时，先恢复服务保存的工作稿和协作进度。

正文编辑与已确认批注保留在工作稿中，不立即写原文件。点 **保存** 或按 Command + S 才把当前正文写回磁盘。服务核对原文件、执行写入并读回，核对成功后登记版本。同一正文不重复新增版本。

点生成前先保留最新输入。保留失败时，输入和批注仍在，任务不交给 Codex。正文变化后无法定位的意见不会被删除。重新选中原句并关联后，才能带上这些意见生成。

批注输入中，Enter 确认，Shift + Enter 换行。中文输入法确认候选文字不提交意见。取消有修改的输入前先确认，取消确认后继续原来的输入。正文的原始 Markdown 和换行需要保真；不支持的结构使用原文编辑方式。
