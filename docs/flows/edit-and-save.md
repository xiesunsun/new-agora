# 编辑与保存

用户可以从文件或文本导入文档，得到工作正文和初始版本 V1。浏览器导入读取选中的 Markdown。要同步回原路径，需要另行[绑定](annotate-and-sync.md)。

| 操作 | 用户可观察的结果 |
| --- | --- |
| 编辑段落 | 输入先留在本机，按 **保存段落** 后提交。取消恢复到进入段落编辑前的内容。 |
| 编辑整篇 Markdown | 面板成批保存。服务接受后更新工作正文，正式版本仍为 V1。 |
| 断线或重开 | 本机草稿可恢复。若远端正文已变，界面保留本机输入并要求核对。 |
| 确认版本 | 工作正文有变化时追加正式版本。前序保存失败时暂停确认。 |

草稿、请求顺序与冲突提示见[面板](../../apps/panel/README.md)。正式版本由[服务](../../apps/service/README.md)维护。验收覆盖 [A02 重复请求](../../tests/README.md#a02)和 [A04 草稿恢复](../../tests/README.md#a04)。
