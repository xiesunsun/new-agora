# 打开文稿与保存草稿

在当前 Codex 对话里打开并绑定一份已有的 Markdown。面板读取原文件作为工作稿，并把首次读取的正文记为 V1。重开同一份文稿时，先恢复已保存的工作稿和协作进度。

编辑时先保存工作稿。面板显示 **草稿已保存**，让你知道这段文字已保留。要把自己的编辑写进磁盘，点 **应用到原文件**。这一步可以单独完成，也可以在审阅完建议后一起完成。

点 **生成修改建议** 前，面板先保存最新输入。保存失败时保留输入并提示重试。本轮开始后，以已经保存的底稿为准。要改底稿或批注，先退出本轮，再从更新后的工作稿生成建议。
