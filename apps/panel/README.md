# 面板

面板提供正文编辑、页边批注、行内审阅和连续历史尺。浏览器与桌面宿主通过同一 mountPanel 和 PanelTransport 使用这套界面。UI 收集输入并展示服务状态，不持久化另一份文稿、审阅或版本模型。编辑器实现放在 `src/editor`。

面板暂存尚未确认的输入，并保留焦点、选区、滚动和展开状态。异步保存与轮询按服务修订接收，较早的响应不能覆盖较晚的输入。生成与保存前先保留最新输入，失败后保留输入并提供恢复操作。

`src/editor/manuscript.ts` 持有 Crepe 原生文档、选区与撤销。工作稿使用同一个实例，批注以不可编辑的装饰节点挂入；历史和审阅期间停放该实例。真正替换正文前核对本地修订，并等待组合输入结束。保存、生成与历史操作先排空本地输入，再调用已有控制器。

`src/editor/manuscript-source.ts` 保存源码与原生结构的快照。仅打开、选字、批注、轮询、浏览历史和无修改保存不重写源码。实际编辑只序列化变化的完整段落、列表、引用、表格或代码结构，保留其他结构、BOM、引用定义与未变更的换行。变化结构中的标记、实体和空白写法可能规范化。回到导入文档的原生撤销恢复原始字节。源位置按当前结构和 UTF-16 区间对应，不搜索重复文字猜测锚点。

普通 Markdown 直接编辑。选区菜单提供行内格式与链接，空行的 `/` 菜单提供标题层级、列表、表格与代码。代码块保留在同一 ProseMirror 文档内，便于精确选字批注。HTML、图片、脚注及特殊链接使用安全阅读与例外的 **编辑原文** 入口；普通工作稿没有源码工具条。原文编辑复用 `exact-text.ts`，保留未修改的源码。HTML 不执行，图片不自动加载，原生图片节点也保持为文字。

无法安全投影的原生编辑保留在编辑器中，最近已保留的源码不被覆盖。面板在正文外提示恢复，提供当前编辑的只读副本和撤销入口，恢复前阻止生成与保存。普通尾空格、空段落和文末输入不属于这种失败。

`src/editor/markdown-syntax.ts` 负责 CommonMark/GFM 结构与区间，`markdown.ts` 负责安全 DOM 呈现和源码映射。`review-document.ts` 继续投影服务保存的修改与选择，`review-view.ts` 解析完整读法后装饰并提取审阅内容，保持列表、链接、强调、代码和标题。视觉分组不产生新的修改编号。原文对照使用紧凑排版，选择后只留下所选正文与中性页边回看标记。

服务决定每项审阅的范围、选择和应用预览。已选建议的回看只改变显示。保存结果以服务对原文件的读回为准，迟到回执只确认原操作。mock 的示例正文、规则和故障控制在开发入口维护，面板不导入它们。

原生样式只从 `panel.css` 导入启用的功能，并由构建统一打包到浏览器 CSS 和桌面内嵌 HTML；编辑脚本不另行导入 CSS。浏览器类型检查配置位于 `tsconfig.json`，和服务端编译检查的分工见[开发与审阅](../../docs/development.md)。
