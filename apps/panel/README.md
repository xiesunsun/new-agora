# 面板

面板展示工作稿、批注和历史。用户可以保存自己的编辑，积累批注，再点 **生成修改建议**。开始前先保存最新输入。保存失败时保留输入并提示，待恢复后再生成。

等待领取时显示 **等待 Codex**。收到服务确认的领取状态后显示 **正在改稿**。提交结果后打开同一个审阅界面，展示实际差异。保留或舍弃一项时更新预览，应用前允许改选。

**应用到原文件** 显示正在写入或待核对。只有服务确认文件读回成功并完成版本登记后，才更新历史和显示 **已写入原文件**。重开面板时恢复工作稿、待审稿和已保存的选择。收到同一应用操作的迟到响应时，更新对应操作的状态。
