# 本地执行工具

Codex 领取本轮任务后，拿到待审 Markdown 路径、批注原话和对应段落。待审文件初始内容是本轮底稿。原路径可提供阅读上下文，写入目标是待审文件。

完成编辑后，用本轮执行身份提交结果。Agora 读取待审稿并保存当时的正文，然后计算实际差异。无修改也可以结束本轮。若提交结果不明，先核对这次提交。确认原执行已经结束后才可以重新生成。

验证时用测试文稿模拟领取、修改待审稿、提交、断线和迟到提交。参见[当前对话领取](../../tests/README.md#a03)和[生成中断](../../tests/README.md#a06)。

## 可配置开发执行器

[mock 场景](../../dev/mock/README.md)独立保存初始文稿、批注、替换规则、结果序列与延迟。执行器通过真实领取、候选文件和提交接口工作。领取后失败或取消时报告匹配执行的结束结果，停止服务前等待此报告完成。

该执行器只在示例入口启动。指定真实文稿与运行目录后不会自动运行。
